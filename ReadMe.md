# JS Master

Веб-приложение для практики и тестирования знаний JavaScript с системой рейтинга и различными режимами проверки.

## О проекте

JS Master - это интерактивная платформа, которая помогает разработчикам улучшать свои знания JavaScript через тестирование. Проект предлагает три режима проверки знаний, таблицу рейтинга для отслеживания прогресса и бесплатный доступ к книге "You Don't Know JS" на русском языке.

### Основные возможности

- Регистрация и авторизация пользователей
- Три режима тестирования:
  - 20 случайных вопросов
  - Все вопросы из базы
  - 20 вопросов по выбранной теме
- Таблица рейтинга с категориями:
  - Личный рейтинг (по проценту правильных ответов)
  - Личный рейтинг (по скорости прохождения)
  - Глобальный рейтинг (по проценту)
  - Глобальный рейтинг (по скорости)
- Ссылка на бесплатную книгу "You Don't Know JS"
- Сохранение всех результатов в локальном хранилище браузера
